# سهم‌بان (Sahm-bân)

اپلیکیشن وب برای مدیریت دارایی‌ها، تعهدات و حساب‌های مشترک میان چند نفر — مناسب خانواده، هم‌خانه‌ها، شراکت‌های مالی یا هر گروهی که سرمایه، هزینه یا بدهی مشترک دارند و می‌خواهند سهم هر نفر را شفاف و قابل ردیابی نگه دارند.

## این پروژه چه کاری انجام می‌دهد

سهم‌بان یک دفتر حسابداری (Ledger) چندنفره و چندارزی است که روی یک «موتور» تراکنش‌محور (`accounting engine`) ساخته شده: هر رویداد مالی به‌صورت یک تراکنش ثبت می‌شود و مانده‌ها، سهم مالکیت و بدهی‌ها از روی همین تاریخچه محاسبه می‌شوند (نه این‌که مستقیم دست‌کاری شوند). این یعنی همه‌چیز قابل حسابرسی (Audit) و بازپخش (Replay) است.

### بخش‌های اصلی برنامه

- **داشبورد (Dashboard):** نمای کلی از وضعیت استخر مالی مشترک (Pool)، نمودار سهم افراد و آخرین تراکنش‌ها.
- **افراد (People):** تعریف اعضا، رنگ اختصاصی هر نفر و درصد سهم آن‌ها.
- **دارایی‌ها (Assets):** ثبت دارایی‌هایی مثل نقد، ارز خارجی، طلا، جواهر، خودرو، ملک، سهام و رمزارز؛ با قیمت تمام‌شده، ارزش روز، مالکیت چندنفره (Ownership Slices) و این‌که هر خرید را چه کسانی پرداخت کرده‌اند (Payer Slices).
- **تعهدات (Obligations):** بدهی‌ها و طلب‌های بین افراد، با مبلغ، ارز، سررسید و مانده باقی‌مانده.
- **دفتر تراکنش‌ها (Ledger):** ثبت انواع تراکنش شامل واریز، برداشت، هزینه، خرید، فروش، انتقال، هدیه، تبدیل ارز، ارزش‌گذاری، تعهد، تسویه و تغییر مالکیت — با تقسیم هزینه (Split) بین افراد.
- **نرخ‌های ارز (Rates):** نگه‌داری نرخ تبدیل ارزها به تومان (IRT) به‌صورت تاریخی، با امکان دریافت نرخ لحظه‌ای/تاریخی از منابعی مثل نوبیتکس.
- **حسابرسی (Audit):** بازپخش کامل دفتر تا یک تاریخ مشخص برای هر فرد و بررسی صحت مانده‌ها.
- **ورودی از اکسل (Import):** ساخت قالب اکسل، خواندن فایل اکسل و تبدیل ردیف‌ها به تراکنش.

### ویژگی‌های فنی مهم

- تقویم و اعداد فارسی/جلالی در کل رابط کاربری (`jalaali-js`).
- چندارزی با نرخ تبدیل مبتنی بر تومان.
- زیرساخت پایگاه‌داده دوگانه: PostgreSQL واقعی (روی محیط دیپلوی) یا PGLite به‌صورت محلی برای پیش‌نمایش، بدون نیاز به نصب دیتابیس جداگانه.
- احراز هویت اختیاری با Better Auth (گوگل، X، یا ایمیل/رمز عبور) که به‌صورت پیش‌فرض خاموش است.
- تست‌های خودکار برای موتور حسابداری، احراز هویت و زمان‌بندی آماده‌سازی داده.

## پشته فناوری (Tech Stack)

- **فرانت‌اند:** React + TanStack Start / TanStack Router + TanStack Table
- **استایل:** Tailwind CSS + Radix UI + کامپوننت‌های سفارشی (shadcn-style)
- **نمودار:** Recharts
- **فرم:** React Hook Form + resolvers
- **پایگاه‌داده:** PostgreSQL (Neon در پروداکشن) / PGLite (پیش‌نمایش محلی)
- **احراز هویت:** Better Auth
- **اکسل:** کتابخانه‌ی داخلی برای ساخت/خواندن Workbook
- **ابزار توسعه:** Vite، ESLint، Prettier، TypeScript
- **دیپلوی:** Vercel (`vercel.json`)

## راه‌اندازی محلی

```bash
npm install
npm run dev
```

سرور توسعه روی `http://localhost:8080` بالا می‌آید.

### اسکریپت‌های مهم

| دستور | کاربرد |
|---|---|
| `npm run dev` | اجرای سرور توسعه |
| `npm run build` | ساخت نسخه‌ی نهایی + اجرای مایگریشن‌های دیتابیس |
| `npm run db:migrate` | اجرای مایگریشن‌های SQL |
| `npm run preview` | پیش‌نمایش نسخه‌ی build‌شده |
| `npm run typecheck` | بررسی نوع‌ها با TypeScript |
| `npm run test` | اجرای تست‌های واحد |
| `npm run lint` | بررسی کیفیت کد با ESLint |
| `npm run format` | فرمت‌دهی خودکار با Prettier |
| `npm run check:auth` | بررسی هماهنگی وضعیت احراز هویت بین dev و build |

## ساختار پوشه‌ها (خلاصه)

```
src/
  routes/            صفحات اصلی: داشبورد، افراد، دارایی‌ها، تعهدات، دفتر، نرخ‌ها، حسابرسی، ورودی اکسل
  components/views/  کامپوننت هر صفحه
  components/ui/     کامپوننت‌های رابط کاربری پایه
  lib/accounting/    موتور حسابداری، انواع داده، خروجی اکسل
  lib/auth/          پیکربندی و گیت‌های احراز هویت
  lib/fx/            دریافت و مدیریت نرخ ارز
  lib/store.ts       مدیریت وضعیت برنامه
migrations/          فایل‌های SQL برای ساخت جداول
scripts/             اسکریپت‌های کمکی توسعه، دیپلوی و تست
```

## نکته درباره‌ی داده‌ها

فعلاً احراز هویت به‌صورت پیش‌فرض غیرفعال است و اطلاعات به شکل محلی/دمو کار می‌کند. برای فعال‌سازی حساب کاربری واقعی و ذخیره‌سازی ابری، باید پرچم `VITE_AUTH_ENABLED` و مایگریشن‌های مربوط به احراز هویت طبق مستندات پروژه فعال شوند.
